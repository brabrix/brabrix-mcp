# Brabrix MCP & VS Code Extension

Official tools for [Brabrix Dev](https://dev.brabrix.com/), the platform for AI-native software engineering.

## 🚀 Overview

This repository contains the official tools to integrate Brabrix Dev into your development workflow:

- **[Brabrix VS Code Extension](./brabrix-dev):** Seamlessly manage your backlog, tasks, and project context directly from VS Code.
- **[Brabrix MCP Server](./brabrix-mcp-server):** A Model Context Protocol (MCP) server that provides AI agents with full context of your Brabrix projects, PRDs, technical specs, and backlog.

## 📦 Components

### Brabrix VS Code Extension (`brabrix-dev`)
Boost your productivity with the Brabrix extension. It allows you to:
- Browse and manage project backlog and tasks.
- Link your local workspace with Brabrix projects.
- Automatically generate PRDs, Technical Specs, and Agent Templates.
- Synchronize Skills & Rules directly to your workspace.

### Brabrix MCP Server (`brabrix-mcp-server`)
Enable AI agents (like Claude or Gemini) to understand your project's business logic and technical requirements.
- Exposes project context, task details, and backlog to AI agents.
- Provides access to Brabrix Skills & Rules.
- **Read-only security:** Safe integration that doesn't modify your remote data.
